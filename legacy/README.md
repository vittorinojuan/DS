# legacy

Versão anterior do site, em `.dc.html` (5 páginas + `support.js`, o runtime do Claude Design). Fica aqui como registro do redesign e como fonte para uma eventual versão multi-página.

**Não é publicável:** depende do `support.js`, tem o texto dentro de arrays JS e não tem SEO. Para ver localmente, sirva esta pasta por HTTP (`npx serve legacy`); abrir por `file://` não funciona. O site publicável está em `../site`.
